# Chelee Portfolio

Personal portfolio website of Chelee, Data Science student. Built with plain HTML, CSS and JavaScript and hosted on GitHub Pages.

Live site: https://chelseawzz.github.io

## Edit the content

Everything (text, projects, certificates, links) lives in `js/data.js`. Change it there and commit. No HTML changes needed.

## Structure

```
index.html      page layout
css/style.css   styling
js/data.js      all content
js/main.js      interactions (filters, case studies, image viewer)
assets/img/     images
```
