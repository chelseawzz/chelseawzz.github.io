# CHELEE Portfolio

Personal portfolio website of CHELEE, Data Science student. Built with plain HTML, CSS and JavaScript and hosted on GitHub Pages.

Live site: https://chelseawzz.github.io

## Edit the content

All text, projects and links live in `js/data.js`. Add a description, tools or a link to any project there and it shows up on the site, no HTML needed.

## Structure

```
index.html      page layout
css/style.css   styling
js/data.js      all content
js/main.js      interactions (filters, popups, typing effect)
assets/         images and the sakura hero scene
```
